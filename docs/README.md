# `docs/` — Current Technical Ground Truth

Files in this directory describe the system **as it actually is today**.
Contrast with `../plans/` — those are the original (June 2026, v1.0)
aspirational design documents, now labeled historical and kept for
reference only.

New ground-truth technical docs go here (or at the project root, like
`PROJECT_DIARY.md` and `DATABASE_AND_TRAINING.md`). If a doc in this folder
ever disagrees with the actual code, the code wins — see each file's own
"source of truth" pointers (e.g. `STRATEGY_ARENA.md` points at
`backend/strategies/promotion_config.py` for gate values).
